The playground checks programs and shows their example traces. To run fn main() or emit a target language (Rust, Python, JavaScript or Scala today), install rce with curl -fsSL https://raw.githubusercontent.com/openIE-dev/rce/main/scripts/install.sh | sh (see the specification README).

    
Host features do not run in the browser: media, the terminal (PTY), TLS between hosts, networking, files and the OS sandbox belong to rce host (Appendix E) and need a native rce build. The playground checks such programs and runs their example traces, which need no host.
