# RCE language specification

- `book/` is the specification, split into chapters small enough to read
  whole. Start at `book/00-overview.md` (abstract and reading map) or
  `book/INDEX.md`. Agents prove they read it with `book/READ-PROTOCOL.md`.
- `RCE-SPEC.md` is the same specification as one file, generated by
  `rce-book build` (formerly `book/build.py`). Edit the book, not this file.
- The normative grammar is the EBNF of section 3 (`book/03-syntax.md`);
  `rce-spec-check` reads it and checks it is LALR(1) with no conflicts
  (the former `rce.lark` and its Lark check are retired).
- `checker/` (Rust only) holds the tools:
  - `rce-spec-check` builds the section-3 LALR(1) tables and regenerates
    the tree-sitter parser (both fail on any conflict), parses `examples/` (must accept) and `examples/reject/`
    (must refuse) with three parsers (section-3 LALR(1) tables, Rust
    parser, tree-sitter), runs the checker, and checks that the
    book and `RCE-SPEC.md` are in sync.
  - `rce-book build [--check]` rewrites (or checks) the chapter footers,
    `INDEX.md` and `RCE-SPEC.md`; `rce-book verify receipt.json` checks a
    read receipt.
  - `rce-fuzz` is the program fuzzer.

```
cd checker && cargo run --release --bin rce-spec-check
```

The default build is pure Rust (Rust parser and LALR(1) only; no C
compiler). CI also runs the tree-sitter cross-checks and the fuzzer, which
compile the C tree-sitter port behind the optional `tree-sitter` feature:

```
cd checker && cargo run --release --features tree-sitter --bin rce-spec-check
cd checker && cargo run --release --features tree-sitter --bin rce-fuzz
```
