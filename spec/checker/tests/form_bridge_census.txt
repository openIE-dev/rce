A whole module's blocker set is every user function's own first refusal.
The walk continues to the next function. It does not continue inside
a function, and it does not change admission: construct still returns
the first refusal. A tag unblocks a whole module when the set is
exactly that tag. A pair unblocks a module when the set is exactly
those two. no-root means the lowered module has no program root
(`fn`, `region`, `delta`, `initial state`). It is not a refusal of
construction, so it is counted with the roots, not as a whole-module tag.

whole is every module whose core constructs and schedules back.
whole-entry-only is that count restricted to entry-only cores: the
lowered core holds only `entry`, because nothing calls the program
functions, so no user code is constructed. It is not a count of user
programs round-tripping. whole-with-user is the same count for cores
that contain at least one user function.
