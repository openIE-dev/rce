About

This page loads @rce/runtime (a wasm-bindgen wrapper around the same Rust crates that power the rce CLI) and runs two real .fg modules end-to-end in your browser.

The CPU path uses the rce-vm-backend-cpu interpreter compiled to wasm32-unknown-unknown. The WebGPU path uses rce-vm-backend-wgpu through wgpu's WebGPU target — same Rust source as the native Metal / Vulkan / DX12 build.

WebGPU requires Chrome stable (M113+), Safari Technology Preview, or Firefox Nightly. If navigator.gpu is missing, only the CPU button works.
